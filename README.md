# Почта IMAP/SMTP для коммуникаций SkeekS CMS

Драйвер `skeeks/cms-communication` для почтовых ящиков на любом сервисе:
Яндекс 360, Mail.ru, Gmail, собственный почтовый сервер. Забирает письма по
IMAP («Входящие», «Отправленные» и выбранные папки), отправляет по SMTP и
кладёт копию в «Отправленные».

Пакет в разработке. Архитектура — в `skeeks/cms-communication/ARCHITECTURE.md`.
