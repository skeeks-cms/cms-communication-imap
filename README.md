# Почта IMAP/SMTP для коммуникаций SkeekS CMS

Драйвер `skeeks/cms-communication` для почтовых ящиков на любом сервисе:
Яндекс 360, Mail.ru, Gmail, Rambler, Outlook, собственный почтовый сервер.
Забирает письма по IMAP («Входящие» и «Отправленные»), отправляет по SMTP и
кладёт копию в «Отправленные». Переносит письма в самом ящике (корзина,
спам, архив, любая папка; `UID MOVE`, на старых серверах — копия и
удаление), находит служебные папки по их отметкам или названиям и ставит
метки как флаги IMAP, где сервер их хранит. Расширение PHP `imap` не нужно.

Установка и настройка — в README пакета `skeeks/cms-communication`.
Архитектура — в `skeeks/cms-communication/ARCHITECTURE.md`, изменения — в
[CHANGELOG.md](CHANGELOG.md).
